	Class, Object & Constructor	


Everything in Python is an object. To create objects of our own custom type, we define a class. A class is the blueprint; an object is the actual thing built from that blueprint.

	Methods	


Instance methods are the most common type of method. They operate on a specific object (instance) and have access to both object variables and class variables through self.



Full Example with Multiple Instance Methods	
BankAccount with instance methods:
class BankAccount:
def  init (self, owner, balance=0): self.owner	= owner self.balance	= balance self.transactions = []

def deposit(self, amount):	# instance method self.balance += amount self.transactions.append(('deposit', amount))
return self.balance

def withdraw(self, amount):	# instance method
if amount > self.balance:
     raise ValueError('Insufficient funds') self.balance -= amount self.transactions.append(('withdraw', amount)) return self.balance

def get_summary(self):	# instance method
return f'{self.owner}: Rs.{self.balance}'

acc = BankAccount('Alice', 1000) acc.deposit(500) acc.withdraw(200) print(acc.get_summary())
# Alice: Rs.1300







A class method is bound to the CLASS itself rather than to any individual object. It receives the class (cls) as its first argument instead of the instance (self).



Primary Use Case - Alternative Constructors	
Class methods are most commonly used to provide alternative ways to create objects:
Alternative constructors with @classmethod:
class Student:school = 'Python Academy'count = 0def  init (self, name, age):self.name = nameself.age = ageStudent.count += 1@classmethoddef from_string(cls, data_string):name, age = data_string.split(',')return cls(name.strip(), int(age.strip()))@classmethoddef get_school(cls):return cls.school	# access class variable@classmethoddef get_count(cls):return cls.countalice = Student('Alice', 21)bob	= Student.from_string('Bob, 19')	# alternative constructorprint(alice.name, bob.name)# AliceBobprint(Student.get_count())# 2print(Student.get_school())# Python Academy








A static method is a regular function that lives inside a class for organisational purposes. It has NO access to self (the object) or cls (the class) - it is completely independent of both.

All Three Together - One Class	
Temperature class using all three method types:
class Temperature:
unit = 'Celsius'	# class variable

def  init (self, degrees):
self.degrees = degrees	# object variable

def describe(self):	# instance method
return f'{self.degrees} {Temperature.unit}'

@classmethod
def from_fahrenheit(cls, f):	# class method - alt constructor
return cls((f - 32) * 5 / 9)

@staticmethod
def is_freezing(degrees):	# static method - pure utility
return degrees <= 0

t1 = Temperature(25)
t2 = Temperature.from_fahrenheit(212)	# 100 C

print(t1.describe())	# 25 Celsius
print(t2.describe())	# 100.0 Celsius print(Temperature.is_freezing(-5))	# True print(Temperature.is_freezing(25))	# False
# 25 Celsius
# 100.0 Celsius # True
# False
